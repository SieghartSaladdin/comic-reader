# Aturan Perilaku

Proyek ini mengikuti [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Ringkasnya:

- Hormati orang lain. Kritik kode dan ide, bukan orangnya.
- Tidak ada pelecehan, hinaan, diskriminasi, atau membuka data pribadi orang lain.
- Terima masukan dengan terbuka, dan beri masukan dengan spesifik.

Pelanggaran dilaporkan lewat pesan pribadi ke pemilik repositori di GitHub (https://github.com/SieghartSaladdin). Pemilik dapat menghapus komentar, menutup issue atau PR, dan memblokir kontributor yang melanggar.
